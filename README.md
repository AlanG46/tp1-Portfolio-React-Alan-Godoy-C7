#Portfolio Personal - Alan Tobias Godoy

Descripción
portfolio personal desarrolado con React y Vite.

El proyecto presenta información sobre mí, Mís habilidades, algunos proyectos y un enlace a mi perfil de github

#Tecnologias Utilizadas

-React
-Vite
-JavaScript
-HTML
-CSS

#Funcionalidades
-Componentes reutilizables.
-El uso de props.
-Renderizado dinámico con arrays y "map()"
-Uso de "Key" en elementos generados Dinamicamente.
-Interacción mediante "Onclick".
-Manejo de estado con "Usestate".
-Renderizado Condicional.
-Diseño Responsive Basico.

##Instalación
Clonar el repositorio:
bash
git clone https://github.com/AlanG46/tp1-Portfolio-React-Alan-Godoy-C7.git

Instalar dependencias:
npm install

Ejecutar el proyecto:
npm run dev

Por ultimo, abrir la dirección que se indique en la terminal presionando Ctrl + Click izquierdo. Ej:http://localhost:5173/
